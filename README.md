# Portfolio

Personal portfolio website showcasing projects and background. Built with vanilla HTML, CSS, and JavaScript.

## Features

- Dark and light theme support with system preference detection
- Bilingual interface (English/Norwegian)
- Project carousel with drag-to-scroll functionality
- Responsive design across mobile, tablet, and desktop
- Dynamic card sizing for optimal viewport utilization
- Persistent user preferences via localStorage

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript
- SVG icons

## Running Locally

Open `index.html` in a web browser. No build process or server required.

## Project Structure

```
.
├── index.html           # Main HTML file
├── styles.css           # Stylesheet
├── script.js            # JavaScript functionality
├── translations.json    # Language strings (EN/NO)
├── favicon.svg          # Site favicon
├── icons/               # UI icons (SVG)
└── img/                 # Project screenshots
```

## Browser Support

Modern browsers with ES6+ support. Tested on Chrome, Firefox, Safari, and Edge.
